# Hi, I'm Jorik 👋

I build and run Minecraft servers, and I write the plugins and tooling that keep them going. Most of my work is in Java on Paper and Velocity, with a bit of PowerShell to hold it all together.

## What I work on

- **Custom server plugins**: gameplay systems, moderation tools and network features for Paper and Velocity
- **Server infrastructure**: multi-server networks, automated setup and backups
- **Small open-source tools**: things I built for my own servers and cleaned up for everyone else
